# Projeto IRSO - Smart Gym

## Getting Started

### Requirements

Make sure you have the following installed:

- **PHP >= 8.5.1** (not tested on versions below)
- **Composer**
- **Node.js & npm**

### Installation

1. Install npm and composer dependencies:

```bash
npm run init
```

This command runs:

```bash
npm install
composer install
```

2. Start the development server:

```bash
npm run dev
```

3. Open your browser and go to:

```bash
http://localhost:8000
```
